# 双路径个性化学习设计

## 目标

根据学情画像和诊断题目证据推断知识点掌握度，生成完整课程路径与默认个性化路径。个性化路径隐藏满足跳过条件的节点，完整路径保留全部节点，并允许学生主动启动被跳过节点。

## 证据规则

- 直接知识点评估是节点掌握度的主要来源。
- 题目必须带有明确的 `concept_id` 才能参与节点聚合。
- 聚合使用正确率、作答稳定性、证据新鲜度和错误模式惩罚。
- 至少 3 道直接关联题、推断掌握度不低于 0.85、置信度不低于 0.80，且无关键错误时，节点才具备跳过资格。
- 只有自我评价而没有题目证据时，不允许自动跳过，只能影响讲解深度。

## 路径契约

- `planning.path` 保持为默认个性化路径，保证现有资源生成 Agent 兼容。
- `planning.full_path` 新增为全量路径，包含所有知识点。
- 两条路径使用同一图谱版本和课程顺序；个性化路径通过节点状态表达跳过结果。
- 被跳过节点不会从后端删除，完整路径可随时恢复其可见性。
- 从完整路径启动节点时，服务端校验硬前置并将该节点作为当前资源生成节点，不改变默认个性化策略。

## 兼容性

现有资源交接只读取 `planning.path` 和 `current_node`，继续接收个性化路径；`full_path` 仅供路径选择和主动启动使用。
