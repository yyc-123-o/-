# 学情诊断 Agent — 项目总结

> 揭榜挂帅比赛（XH-202630 上海云之脑智能科技有限公司 — 领域知识个性化生成与多智能体协同决策系统）
> 本 Agent 负责系统中的**学情诊断**环节，完成学习者画像构建与知识盲区诊断。

---

## 一、项目定位

学情诊断 Agent 是整个多智能体系统的**入口模块**，承担以下职责：

1. 采集学习者信息（自填问卷 + 自适应测试 + 上传数据）
2. 基于 **IRT-2PL 项目反应理论** 动态评估能力参数 θ
3. 构建**四维学习者画像**（知识点掌握度、能力等级、错误模式、学习偏好）
4. 输出**章节级资源生成提示**，驱动下游「资源生成 Agent」等模块

## 二、完成的六大核心任务

### 任务 1：IRT 能力评估引擎

| 模块 | 完成内容 |
|------|----------|
| `core/irt.py` | 2PL-MLE 最大似然估计 θ，含 L2 正则先验收缩、全对/全错边界处理、学历先验（专科-0.5/本科0.0/硕士0.5/博士1.0） |
| `core/mastery.py` | 每个知识点掌握度计算（IRT + 交互行为修正 + 稀疏数据兜底），输出掌握度/θ/测试数/置信度/状态六元组 |

### 任务 2：知识图谱与学习路径

| 模块 | 完成内容 |
|------|----------|
| `models/knowledge_graph.py` | 5 大领域 × 30 个知识点，含 DAG 前置依赖关系 |
| 章节定义 | 6 章学习路径（ch01 数学基础回顾 → ch06 Transformer），含前驱/共需/后继拓扑 |
| `core/gap_analyzer.py` | 4 类知识盲区（盲区/薄弱/阻塞/困难）+ 优先级排序 + 置信度 + 建议操作 |

### 任务 3：完整题库知识库（131 道真实题目）

| 指标 | 数值 |
|------|------|
| 题目总数 | 131 道 |
| 覆盖知识点 | 30 / 30（全覆盖） |
| 难度分层 | 低难度 32 / 中等难度 60 / 高难度 39 |
| 领域分布 | 数学26 / 机器学习29 / 深度学习26 / 优化25 / 实践25 |

每道题包含：**知识点归属 + 难度分层（低/中/高）+ 题干 + ABCD选项 + 正确答案 + 解析**。

### 任务 4：四维学习者画像（对齐 0803 方案）

画像输出为 **14 个顶层字段**：

```
learner              → 基本信息（姓名/学历/五维自评/项目经历）
learning_scope       → 章节级学习范围（当前章节/目标知识点/目标深度）
knowledge_mastery    → 知识点掌握度矩阵（含置信度）
ability_level        → 能力等级（4 子维度评分）
error_patterns       → 错误模式四分类（概念混淆/计算错误/逻辑跳跃/忽略条件）
learning_preferences → 学习偏好（格式/风格/节奏/交互/动机）
knowledge_gaps       → 知识盲区清单
depth_labels         → 30 知识点深度标签（skip/review/entry/advanced）
resource_generation_hints → 章节级资源生成提示（直接驱动资源生成Agent）
prior_chapters       → 前序章节表现
evidence             → 证据溯源（每条结论可追溯）
diagnosis_summary    → 诊断摘要
meta                 → 元信息
```

**关键机制**：
- 每个关键字段带**置信度**（如 CNN 掌握度 0.70、概念混淆比例 0.87）
- 每条画像结论带**证据溯源**，回应比赛"幻觉可控"要求

### 任务 5：自适应测试（按领域分类 + 先易后难 + 困难定级）

`core/adaptive_test.py` 实现三阶段递进出题逻辑：

```
按 5 大领域逐领域测试（数学基础 → 机器学习 → 深度学习 → 优化 → 实践）
  每个领域内：低难度 → 中等难度 → 高难度
  连续答对 2 题 → 晋升下一难度
  连续答错 3 题 → 定级为当前难度 → 进入下一领域
  通过全部难度 → 定级高难度
```

**掌握水平 = 用户卡住的难度档**：先易后难，困难即定级。

### 任务 6：四通道数据输入 + Web 交互界面

| 输入通道 | 说明 |
|----------|------|
| 自填问卷 | 个人信息（填空+选择）+ 五维课程自评 + 项目经历 |
| 上传 JSON | 粘贴完整学习者数据 |
| 自适应测试 | 逐题作答，自动判题，θ 实时更新 |
| 章节切换 | 选择目标章节（ch01~ch06） |

前端（`static/index.html`）提供四个 Tab 面板 + ECharts 可视化（雷达图/热力图/盲区表）。
