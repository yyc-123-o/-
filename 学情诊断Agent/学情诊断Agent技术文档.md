# 学情诊断 Agent 技术文档

## 一、系统概述

学情诊断 Agent 是一个基于 **FastAPI + IRT（项目反应理论）** 的智能学习诊断系统，能够自动收集、分析学习者的多维数据，构建完整的学习画像，并提供针对性的学习建议。

---

## 二、学情数据来源与掌握度计算

### 2.1 数据来源

系统从**四个维度**收集学习者数据：

| 数据来源 | 数据类型 | 采集方式 | 说明 |
| :--- | :--- | :--- | :--- |
| **自适应测试记录** | `TestRecord` | 用户在测试中的答题行为 | 包含题目 ID、对错、用时、题目难度等 |
| **自填问卷** | `SelfAssessment` | 用户主动填写的五维领域自评 | 包含三档掌握度选择（未学过/基本了解/熟练掌握） |
| **交互行为记录** | `InteractionRecord` | 用户的浏览、练习、讨论行为 | 包含学习时长、交互类型等 |
| **学历背景** | `Education` | 用户注册时填写 | 学历层次作为能力估计的先验信息 |

### 2.2 掌握度计算流程

#### Step 1：学历先验 θ 映射
根据用户学历层次，映射出一个初始能力值 θ：

```python
EDUCATION_PRIOR_THETA = {
    "专科": -0.5,
    "本科": 0.0,
    "硕士": 0.5,
    "博士": 1.0,
}
```

#### Step 2：IRT 能力估计（权重最高）

**数据充足（≥ 2 题）**：使用 IRT 2PL 模型（双参数模型）进行极大似然估计（MLE）。

- **公式**：`logit(P(正确)) = a × (θ - b)`
- **参数说明**：
  - `a`：题目区分度（由题库定义）
  - `b`：题目难度（由题库定义）
  - `θ`：学习者潜在能力值
- **权重分配**：每道题的权重由其区分度 `a` 自动决定，区分度高的题目对 θ 估计影响更大。

**数据不足（1 题）**：采用先验 + 单题修正
```python
theta = prior_theta  # 学历对应的先验值
theta += 0.3 if is_correct else -0.3  # 答对+0.3，答错-0.3
```

**无测试数据**：使用纯先验 θ

#### Step 3：转化为基础掌握度
将 θ 值与知识点难度结合，计算 [0, 1] 区间的掌握度：

```python
mastery = sigmoid(theta - kp_difficulty)
# mastery = 1 / (1 + exp(-(theta - kp_difficulty)))
```

#### Step 4：交互行为修正（权重最低，微调）

基于用户交互记录进行 ±0.05 ~ 0.15 范围的微调：

| 交互行为 | 修正方向 | 权重 | 说明 |
| :--- | :--- | :--- | :--- |
| **练习次数多** | 正向 + | 中等 | 每多练一次 +0.03（上限 0.15） |
| **讨论活跃** | 正向 + | 低 | 每多讨论一次 +0.02（上限 0.06） |
| **纯看书不练习** | 负向 - | 低 | 浏览 ≥3 次但无练习 -0.05 |
| **时长异常长** | 负向 - | 中等 | 学习 >30 分钟但练习极少 -0.08 |

### 2.3 权重分配总结

| 数据来源 | 权重 | 影响方式 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **自适应测试记录** | ★★★★★ 决定性 | 直接决定 θ 估计值 | 有 ≥2 题时完全主导掌握度计算 |
| **自填问卷** | ★★★☆☆ 补充/兜底 | 无测试数据时直接采用自评值 | 冷启动、测试稀疏时 |
| **交互行为记录** | ★★☆☆☆ 微调 | 小范围修正掌握度 | 有测试数据时作为辅助修正 |
| **学历背景** | ★☆☆☆☆ 先验/正则 | 提供初始 θ 值 | 数据稀疏时的起始点 |

### 2.4 掌握度等级映射

| 掌握度分值区间 | 状态标签 | 含义 |
| :--- | :--- | :--- |
| `≥ 0.75` | **熟练 (mastered)** | 掌握良好，可进阶学习 |
| `0.60 ~ 0.75` | **熟悉 (familiar)** | 有一定基础 |
| `0.40 ~ 0.60` | **部分掌握 (partial)** | 有基础但不牢固 |
| `0.25 ~ 0.40` | **薄弱 (weak)** | 正确率较低，需重点学习 |
| `0.10 ~ 0.25` | **未学 (not_learned)** | 入门阶段 |
| `< 0.10` | **未探索 (unexplored)** | 无答题记录 |

## 三、自适应测试模块

### 3.1 题库分布

#### 知识图谱结构
系统包含 **30 个知识点（kp_001 ~ kp_030）**，分布在 **5 大领域**：

| 领域 | 知识点编号 | 数量 |
| :--- | :--- | :--- |
| **数学基础** | kp_001 ~ kp_005, kp_026 | 6 个 |
| **机器学习基础** | kp_006 ~ kp_010, kp_027 | 6 个 |
| **深度学习** | kp_011 ~ kp_015, kp_028 | 6 个 |
| **优化算法** | kp_016 ~ kp_020, kp_029 | 6 个 |
| **实践应用** | kp_021 ~ kp_025, kp_030 | 6 个 |

#### 题库特点
- **总题量**：113 题（每个知识点至少 2 题）
- **难度分布**：每个知识点覆盖低、中、高至少 2 档
- **题目类型**：纯概念题（无计算题），简单代表性强
- **筛选标准**：
  - 不考具体数值计算
  - 题目贴合所属知识点
  - 难度梯度合理，能区分用户水平

### 3.2 难度等级定义

| 难度档 | 难度值范围 | 说明 |
| :--- | :--- | :--- |
| **低难度** | `[-3.0, -0.2)` | 基础概念，识记层 |
| **中等难度** | `[-0.2, 0.8)` | 概念理解与简单应用 |
| **高难度** | `[0.8, 3.0]` | 综合应用与辨析 |

### 3.3 动态选题逻辑

系统采用**两阶段选题策略**：

#### Phase 1：全覆盖优先（核心阶段）
```
目标：覆盖所有 30 个知识点，每个先出 1 道代表题

步骤：
1. 从「尚未出过题的知识点」中收集所有未答题目作为候选池
2. 在候选池中选择「题目难度 |difficulty - current_θ| 最小」的一题
3. 每答一题 → 更新 θ → 继续选择下一题
```

#### Phase 2：代表性补充（覆盖完成后）
```
目标：给每个知识点至少 2 道题，保证评估准确性

步骤：
1. 给「只出过 1 题的知识点」再补 1 道难度匹配的题
2. 补充时使用相同的「难度匹配」策略
3. 若需继续出题，改用标准 IRT：选择「当前 θ 处 Fisher 信息量最大」的题目
```

### 3.4 初始难度确定

根据用户学历层次映射初始 θ 值，决定第一道题的难度：

| 学历层次 | 初始 θ | 起始难度 |
| :--- | :--- | :--- |
| 专科 | -0.5 | 低难度区 |
| **本科** | **0.0** | **中等难度区** |
| 硕士 | 0.5 | 中高难度区 |
| 博士 | 1.0 | 高难度区 |

### 3.5 停止测试逻辑

测试在以下三种情况之一发生时自动停止：

| 停止条件 | 说明 | 优先级 |
| :--- | :--- | :--- |
| **核心停止** | 已覆盖知识点 ≥ 25 个 **且** 答题数 ≥ 25 题 | 最高 |
| **硬上限保护** | 答题数达到 40 题 | 高 |
| **题库耗尽** | 30 个知识点的题目全部答完 | 低 |

### 3.6 动态调整机制

用户每答一题，系统实时更新 θ 值：

- **连续答对 3 题** → θ 快速上升 → 后续题目难度逐渐加大
- **连续答错** → θ 快速下降 → 后续题目难度逐渐降低
- **θ 收敛稳定** → 题目难度在用户实际水平附近波动

## 四、画像看板模块

### 4.1 模块组成

画像看板包含以下核心数据图：

| 图表名称 | 图表类型 | 数据来源 | 分析目的 |
| :--- | :--- | :--- | :--- |
| **能力雷达图** | 雷达图 | 各领域掌握度均值 | 展示 5 大领域的综合能力对比 |
| **知识点掌握度热力图** | 热力图 | 每个知识点的 mastery 值 | 直观展示 30 个知识点的掌握程度分布 |
| **盲区分析表** | 表格 | gap_analyzer 输出 | 列出需要优先攻克的薄弱点 |
| **领域评估雷达** | 雷达图 | 模式2引导问答结果 | 展示用户自评的五维领域能力 |

### 4.2 各图表数据来源

#### 能力雷达图
- **数据来源**：`KnowledgeMastery.domain_summary`
- **计算方式**：每个领域内所有知识点掌握度的均值
- **展示内容**：5 大领域的综合掌握度对比

#### 知识点掌握度热力图
- **数据来源**：`KnowledgeMastery.points`
- **计算方式**：
  - 有测试数据：IRT 估计的 mastery 值
  - 无测试数据但有自评：直接采用自评 mastery 值
  - 无任何数据：显示为 "未探索"
- **可视化**：
  - 横轴：5 大领域
  - 纵轴：30 个具体知识点
  - 颜色：红（低掌握）→ 黄（中掌握）→ 绿（高掌握）

#### 盲区分析表
- **数据来源**：`gap_analyzer.analyze()` 输出
- **分析逻辑**：
  - 知识点掌握度 < 0.5 且是前置依赖 → 判定为「阻塞性盲区」
  - 知识点掌握度 0.35 ~ 0.5 → 判定为「薄弱点」
  - 知识点掌握度 < 0.25 → 判定为「困难点」
- **输出字段**：优先级、盲区类型、知识点名称、掌握度、置信度、建议行动

### 4.3 数据分析流程

#### Step 1：领域能力聚合
```python
# 计算每个领域的平均掌握度
for domain in ["数学基础", "机器学习基础", ...]:
    domain_mastery[domain] = np.mean([
        kp.mastery for kp in points if kp.domain == domain
    ])
```

#### Step 2：能力等级判定
```python
def get_ability_level(global_theta):
    if global_theta < -0.5:
        return "初学者"
    elif global_theta < 0.8:
        return "中级"
    else:
        return "高级"
```

#### Step 3：子维度能力评估
```python
sub_dimensions = {
    "theoretical_understanding": mastery(kp_008) * 0.7 + mastery(kp_015) * 0.3,
    "coding_ability": 0.70,  # 基于问卷自评
    "mathematical_foundation": avg(mastery(kp_001~kp_005)),
    "problem_solving": mastery(kp_009) * 0.5 + mastery(kp_025) * 0.5 + 0.2,
}
```

### 4.4 诊断结果输出

系统最终输出 `LearnerProfile` 结构，包含 14 个核心字段：

| 字段 | 说明 |
| :--- | :--- |
| `ability_level` | 综合能力等级（beginner/intermediate/advanced） |
| `knowledge_mastery` | 30 个知识点的掌握度矩阵 |
| `domain_summary` | 5 大领域的掌握度汇总 |
| `knowledge_gaps` | 识别出的知识盲区列表 |
| `error_patterns` | 主要错误模式分类 |
| `learning_preferences` | 学习偏好（格式、节奏、动机等） |
| `depth_labels` | 每个知识点的建议教学深度 |
| `resource_generation_hints` | 章节级资源生成提示 |
| `evidence` | 诊断证据溯源记录 |

### 5.2 核心模块说明

| 模块 | 文件路径 | 功能说明 |
| :--- | :--- | :--- |

| `/api/adaptive-test/session` | GET | 查看当前会话状态 |

## 六、使用指南

### 6.1 启动服务
```bash
cd "学情诊断Agent 0825更新"
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### 6.2 访问系统
- 前端界面：`http://127.0.0.1:8000/static/index.html`
- API 文档：`http://127.0.0.1:8000/docs`

### 6.3 典型使用流程
1. **选择学习者**：从下拉菜单选择一个预设学习者
2. **填写问卷**：完成五维领域自评（三档掌握度选择 + 引导问答）
3. **自适应测试**：点击「开始测试」，系统自动出题
4. **查看画像**：测试完成后查看画像看板的数据分析
